공개자료 MVP

1. 무엇을 확인할까요?

기본 공개자료 snapshot을 사용합니다. 로컬 JSON packet을 선택하면 같은 검증 흐름으로 재실행합니다.
입력한 문장은 실행 기록에 남고, 요청에 맞는 확인 순서를 자동으로 고릅니다.
직접 입력해 볼 문장: “대상 기업의 FY2025와 비교기업의 9M FY2026 실적을 비교해줘”
기본 경로는 모델 없이 실행합니다. LLM을 연결할 때는 기관 승인 gateway와 모델 allowlist를 통과한 경우만 사용합니다.
공개자료 묶음을 사용한 MVP 실행입니다. 실제 투자판단에 사용하지 않으며, SEC·시장데이터 사용 조건을 최종 확인해야 합니다.
