## 재현 기록

- snapshot: `mvp/data/real_case_snapshot_2026-11-05.json`
- benchmark: `mvp/data/benchmark_holdout20_offline_result.json`, `benchmark_holdout20_offline_repeat01_result.json`
- 현재 실행 기본값: 모델 없음, `observable_policy_v1` 결정론적 통제군
- 과거 모델 raw response는 공개 제출의 모델 성능 근거로 사용하지 않는다.
- 모든 공개 실행·판정·실행일·오류 여부를 JSON으로 보관한다.
- 데이터 파일의 SHA-256은 제출 직전에 산출하여 제출 manifest에 고정한다.

## 금지 범위

- Yahoo snapshot을 KIC 운영용 실시간·상용 데이터 feed로 설명하지 않는다.
- API key·내부 문서·개인정보를 release ZIP 또는 public repository에 넣지 않는다.
- 공개자료 snapshot의 수치를 KIC 내부 데이터나 투자 추천으로 표현하지 않는다.
- 특정 국가·특정 로컬 모델을 기관 운영 기본값으로 지정하지 않는다. LLM 연결은 승인된 private endpoint와 allowlist를 통과한 경우에만 허용한다.

## 공식 규정과의 연결

외부 데이터·모델·API 사용은 공모전 규정의 허용 범위 안에서 수행하되, 각 자원의 출처·사용조건·라이선스를 제출물과 저장소에 기록한다. 최종 서비스는 원자료를 단순 복제하지 않고 typed state, deterministic calculation, evidence ledger, hold policy를 결합한 독창적 workflow로 제공한다.
