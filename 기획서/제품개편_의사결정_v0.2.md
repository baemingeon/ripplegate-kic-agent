# 제품 개편 의사결정 v0.2

작성일: 2026-11-07

## 개편 결론

제출물과 사용자 화면의 현재 제품명은 `IC Preflight (아이씨 프리플라이트)`로 통일한다. `투심렌즈 (IC Lens)`와 `IC Proof`는 이전 검토안이며, `심의나침반`과 `IC-Gate`는 과거 산출물의 역사적 명칭으로만 남긴다. 공개 제출 패키지에는 현재 제품명만 포함한다.

## 제품이 해결하는 문제

분석가는 기업·Peer의 자료를 모아 투자심의용 비교를 만들 때 기간, 정의, 단위, 통화, 가격 기준일이 어긋난 자료를 만날 수 있다. 일반적인 검색·요약 답변은 숫자가 그럴듯하면 계산을 계속할 수 있지만, IC Preflight는 정합성이 확인되지 않은 계산을 멈추고 다음 확인 지점을 넘긴다.

## KIC와의 관계

KIC의 공개 투자 프로세스는 투자 목표·분석·자산배분·운용계획·실행·모니터링의 전체 흐름이다. IC Preflight는 이 흐름을 재설계하지 않는다. 공개자료에서 확인 가능한 위원회·리스크 검토 전 단계에 다음 품질 게이트를 붙이는 MVP 업무 가설이다.

`자료 수집 → 기준일·정의·단위 확인 → valuation·민감도 계산 → 근거·리스크 확인 → 투자심의팩`

핵심 산출물은 투자 결론이 아니라 `진행`, `추가자료`, `보류` 상태와 사람에게 넘길 이유다.

## 실제 MVP 범위

- 대상: 기업 1개와 후보 Peer 3개
- 데이터: 공개 SEC·IR·가격 snapshot
- 계산: 멀티플과 간단한 민감도
- Agent: 목표 라우팅, Tool allowlist, 재계획, typed Verifier, human handoff
- 화면: 입력, 진행 상태, 심의팩, 근거 목록, 상세 trace, 감사 로그

## AI·규칙·사람의 경계

| 담당 | 하는 일 | 하지 않는 일 |
|---|---|---|
| LLM | 요청 구조화, 다음 확인 순서, 설명 초안 | 숫자 승인, 최종 HOLD 결정 |
| 결정론적 모듈 | 기간·정의·단위·통화·계산·출처 gate | 투자 판단의 맥락 전체 해석 |
| 사람 | 자료·가정 확인, 최종 심의·거래 결정 | 없음 |

## 보안·실행 환경

기본 경로는 모델이 없어도 동작한다. 승인 LLM을 연결하려면 provider·model allowlist·private endpoint·secret 주입 정책을 통과해야 한다. allowlist 실패, timeout, JSON 오류가 나면 결정론적 fallback으로 전환한다. 현재 개발 PC는 i5-12400F·16GB RAM·RTX 3050 4GB이며, 모델 없는 MVP 경로를 기본 검증했다.

## 가독성

첫 화면은 업무 언어로 고정한다.

`자료 찾기 → 기준 맞추기 → 심의팩 만들기`

상세 기술 용어는 펼침 영역으로 보내며, 본문을 줄여 빈 공간을 채우지 않는다.
