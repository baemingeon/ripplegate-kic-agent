## 제출 전 입력

`team_info.template.json`을 `team_info.json`으로 복사하고 팀명·팀장·팀원·연락처를 입력한다. 개인 정보가 포함된 `team_info.json`은 GitHub 공개 저장소에 올리지 않는다.

## 버전 관리 원칙

v0.9.2 이전 PPTX·PDF·ZIP·영상은 비교·검증용 작업 기록이다. 제출에는 현재 정본만 사용한다. 이전 서비스명과 특정 로컬 모델 실험 문구는 역사 기록이며 현재 공개 제품·기획서·MVP의 운영 기준이 아니다.
