## 제출 직전 심사 질문 점검

1. 왜 단순 RAG가 아닌가? → 검색이 아니라 기준일·정의·단위·Peer 적합성의 정합성을 판정하고 unresolved이면 보류하기 때문이다.
2. 전부 보류하면 안전한 것 아닌가? → 정상 케이스를 REVIEW로 보내는 false-hold rate를 별도 측정하며, 목표는 선택적 보류다.
3. 같은 LLM이 검증하는가? → 아니다. LLM은 계획·Reflection만 제안하고 Decimal Calculator·typed Verifier가 최종 게이트다.
4. 오류를 주입한 것 아닌가? → base와 별도로 신규 오류·표현 변경 stress20을 보관하고 동일 조건 2회 재현 로그를 제시하되, 일반화 성능으로 과장하지 않는다.
5. 내부자료를 외부 API로 보내는가? → MVP는 공개자료만 사용하며, 운영 전환은 private endpoint 또는 승인된 사내 모델·권한정책을 통과한 뒤다.
