## 본선에서 보여줄 장면

1. 재현 문장 입력
2. 기간 불일치 자동 라우팅
3. 원문 재조회와 재계획
4. 계산 Tool 사전조건 차단
5. HOLD와 보류 이유
6. 원문 링크·fingerprint·human handoff

## 예상 질문의 짧은 답

- 전부 HOLD하면 안전한가? 정상 케이스와 false-hold를 함께 측정한다.
- 같은 LLM이 검증하는가? 아니다. LLM은 제안하고 typed Verifier와 Decimal Calculator가 게이트를 맡는다.
- 중국산 모델인가? 공개 기본 경로는 모델이 없고, 승인 LLM도 allowlist와 private endpoint를 통과해야 한다.
- 통화가 다르면 임의로 환산하는가? 아니다. 승인된 환율 snapshot의 기준일·출처가 없으면 환산과 valuation을 차단하고 `HOLD`로 담당자에게 넘긴다.
- PC가 약하면? 현재 MVP는 GPU 없이 실행하며 LLM은 선택 Adapter다.
- KIC 내부 SOP를 재현했는가? 아니다. KIC 공개자료에 연결한 업무 가설이며 실제 SOP는 확인 전이다.

효과 수치 잠금: 사람 stopwatch와 Agent end-to-end 기록이 P01~P05 모두 존재하기 전에는 시간절감률을 발표하지 않는다. 현재 정본은 `AWAITING_HUMAN_PAIRING` 상태다.
