## 핵심 포지션

IC Preflight는 KIC 공개 투자 프로세스를 대체하지 않는다. 투자심의 전 공개자료·계산·리스크 조건을 확인하고, 문제가 남으면 `추가자료` 또는 `보류`로 담당자에게 넘기는 품질 게이트다.

심사위원 재현 문장:

> 대상 기업의 FY2025와 비교기업의 9M FY2026 실적을 비교해줘

기대 결과:

`기간 확인 실패 → 다시 확인 → 해소되지 않으면 HOLD`

## 실행

```powershell
cd "C:\Users\bmg37\kic 국부펀드"
python .\mvp\server.py
```

브라우저에서 `http://127.0.0.1:8765`를 열고 `모델 없이 안전 확인`을 유지한다. `자동 확인`으로 둔 뒤 재현 문장을 입력하면 기간 불일치 경로를 자동 선택한다.

첫 화면에서는 `자료 찾기 → 기준 맞추기 → 계산 → 검증 → 심의팩`의 상태와 최종 심의팩을 먼저 보여준다. 상세 trace와 근거 fingerprint는 펼침 영역에서 확인한다.

## 최종화

팀 정보가 준비되면 `기획서\team_info.json`을 만들고 다음을 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File .\mvp\finalize_submission.ps1
```

스크립트는 팀 정보를 표지에 주입하고 PPTX·PDF·pilot evidence·공개 release ZIP·fresh release validator·workspace validator를 같은 버전으로 다시 만든다.

## 모델 정책

기본 경로는 모델이 필요 없다. 승인 모델을 연결할 때는 `KIC_LLM_POLICY=approved`와 `KIC_LLM_ALLOWED_MODELS`를 함께 설정한다. allowlist 밖의 모델은 호출하지 않는다. 현재 개발 PC는 i5-12400F·16GB RAM·RTX 3050 4GB이며 모델 없는 안전 게이트를 기본 실행 경로로 검증했다.

## 제출 전 남은 입력

- 팀명·팀장·팀원·연락처
- Demo URL
- GitHub URL
- 동일 packet의 실제 수작업 stopwatch와 Agent end-to-end 측정

실제 업무효과 수치와 공개 링크는 입력 전까지 주장하지 않는다.
